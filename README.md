# Loan Default Risk Demo

เว็บเดโมทำนายความเสี่ยงผิดนัดชำระสินเชื่อด้วย XGBoost (เพื่อการศึกษาเท่านั้น)

- ชุดข้อมูล: BuildersLab/loan-application-dataset (LendingClub 2007-2018, CC0)
- โค้ดเทรนและวัดผล: โน้ตบุ๊ก Google Colab (ใส่ลิงก์โน้ตบุ๊กที่นี่)
- ไฟล์ในโฟลเดอร์นี้สร้างจากโน้ตบุ๊กนั้น: `model.json` และ `meta.json` (cell 12), `streamlit_app.py` และ `requirements.txt` (cell 13)
- ข้อจำกัดและความเป็นธรรม ดูในแท็บ Responsible AI ของเว็บ
